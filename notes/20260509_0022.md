## 学習内容: 01_micrograd（自動微分）

### 自動微分とは

LLMの学習は「パラメータを少しずつ調整する」こと。  
その調整量（勾配）を計算するのが自動微分。  
`engine.py`（94行）でその核心が実装されている。

### Value クラスの要点

```python
self.data = data        # 値そのもの
self.grad = 0           # 勾配（backward()後に埋まる）
self._prev = set(_children)  # 「どの値から生まれたか」を記憶
self._backward = lambda: None  # 勾配の逆流方法（演算ごとに上書き）
```

### 演算ごとの勾配（連鎖律）

| 演算 | dc/da | コード |
|------|-------|--------|
| `c = a + b` | 1 | `self.grad += out.grad` |
| `c = a * b` | `b`（相手の値） | `self.grad += other.data * out.grad` |
| `c = a ^ n` | `n * a^(n-1)` | `self.grad += (n * a^(n-1)) * out.grad` |

**掛け算では「相手の値」が勾配の倍率になる。**  
足し算では「1倍そのまま」なので `× 1` を省略している。

### `+=` が必要な理由

同じ変数が複数回使われた場合（例: `a*a`）、勾配は足し合わさる。

### backward() の流れ

1. 計算グラフをトポロジカルソート（依存関係順に並べる）
2. `self.grad = 1`（出力自身の勾配 = 1）
3. 逆順に `_backward()` を呼んで勾配を上流へ伝播

### 自動微分の使い方（学習ループ）

```python
# forward: 予測して損失を計算
y_pred = w * x + b
loss = (y_pred - y_true) ** 2

# backward: 勾配を計算
loss.backward()

# update: パラメータを勾配の逆方向に動かす
w.data -= lr * w.grad
b.data -= lr * b.grad
```

これを繰り返すことで損失が小さくなり、モデルが学習する。  
LLMも同じ仕組みをパラメータ数十億個に対して行っている。
