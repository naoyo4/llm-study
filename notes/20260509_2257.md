### 2. 04_makemore_activations のサンプル作成

**ファイル**: `04_makemore_activations/makemore_activations.ipynb`（18セル）

学習した4つのテーマ：

| テーマ | 問題 | 解決策 |
|--------|------|--------|
| ホッケースティック | W2 が大きすぎて初期 loss が異常に高い | `W2 *= 0.01` |
| tanh 飽和 | hpreact が広がりすぎてニューロンが死ぬ | Kaiming 初期化 |
| 勾配消失 | 逆伝播の途中で勾配が 0 に近づく | 上記2つで改善 |
| 学習中の分布ズレ | 初期化だけでは学習中に崩れる | Batch Normalization |

**Kaiming 初期化の式**:
```
std = (5/3) / sqrt(fan_in)
fan_in = n_embd × block_size = 10 × 3 = 30
```

**BatchNorm の仕組み**:
```python
bnmean = hpreact.mean(0, keepdim=True)
bnstd  = hpreact.std(0, keepdim=True)
hpreact_norm = (hpreact - bnmean) / (bnstd + 1e-5)
hpreact_bn   = gamma * hpreact_norm + beta  # gamma, beta は学習パラメータ
```

### 3. 05_makemore_backprop のサンプル作成

**ファイル**: `05_makemore_backprop/makemore_backprop.ipynb`（28セル）

`loss.backward()` が内部でやっていることを手動で再現。

各演算の逆伝播：

| 演算 | 逆伝播 |
|------|--------|
| `y = x @ W` | `dx = dy @ W.T`, `dW = x.T @ dy` |
| `y = tanh(x)` | `dx = dy * (1 - y²)` |
| cross_entropy | `d(logits) = softmax(logits) - one_hot(y)` |
| BatchNorm | 平均・分散の経路を全部辿る（最難関） |

`cmp()` 関数で PyTorch の自動微分と一致するか検証しながら実装。
